# Título
Tecnologia assistiva para Libras ;)

## 📒 Descrição
O objetivo será construir um sistema que receba texto ou fala como entrada e exiba um avatar realizando os sinais correspondentes.

## 🤖 Tecnologias utilizadas
Reconhecimento de Fala (opcional):
Whisper (OpenAI) ou Google Speech-to-Text API.
Processamento de Texto:
Hugging Face Transformers ou GPT para transformar frases em glosses de Libras.
Representação Visual:
MediaPipe ou um motor gráfico como Unity com suporte a avatares.
Linguagem de Desenvolvimento:
Python para o backend (modelo e processamento).
Unity/C# ou uma ferramenta web para exibir o avatar.

## 🧐 Processo de Criação
Decida a abordagem inicial: somente texto ou incluir reconhecimento de fala.
Escolha como o avatar exibirá os sinais (MediaPipe ou Unity).
Monte um MVP básico para testar o fluxo completo.
Treine o modelo ou implemente APIs externas para expandir o vocabulário.


## 🚀 Resultados
Uma poderosa ferramenta de inclusão utilizando IA, onde traria autonomia para os deficientes auditivos serem atendidos de forma igualitária aos demais clientes.

## Reflexão
